description: "A command-line tool and Python library for sampling sequencing reads with replacement, so a single FASTQ file can be resampled into many bootstrap replicates for uncertainty quantification at the level of raw reads — answering questions like whether a low-abundance call would survive resequencing. It streams large libraries efficiently (a full bootstrap of a 500-million-read library in under 30 minutes at 9.4 GB peak memory, or 1.4 GB in low-memory mode), and its replicates recover the multinomial sampling uncertainty of transcript abundance estimates to within a few percent on real yeast RNA-seq data."
