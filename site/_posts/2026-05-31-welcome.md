## How to write a post

1. Create a file in `site/_posts/` named `YYYY-MM-DD-title.md`.
2. Add YAML front matter (the block between the `---` lines above):
   - `title`, `date`, and an optional `excerpt` (shown in the blog list).
   - `tags:` — a list of topics. These automatically build the
     [Tags page](/tags/) (e.g. machine learning, bioinformatics, radiology).
   - `comments: true` enables the giscus comment thread at the bottom.
3. Write the body in Markdown below the front matter.

Code blocks, math, and images all work:

```python
print("hello, world")
```
